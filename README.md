# School and Academic Management System

An all-in-one educational platform and school management portal designed to streamline academic operations, curriculum timetables, student accounts, and student guidance through integrated AI assistance.

---

## Key Features

- Academic Routine Builder: AcademicRoutineBuilder dynamically schedules classes, teacher assignments, and period rooms.
- Integrated AI Student Advisory: AIChatDrawer provides instant AI assistance for students regarding syllabus, exams, and notices.
- Tuition and Accounts Management: AccountManagementModal handles student tuition invoices, fee collection, and financial logs.
- Student and Teacher Directory: Comprehensive profiling for students, faculty members, and administrative staff.
- Academic Analytics: Clean dashboards tracking attendance rates, exam scores, and institutional metrics.

---

## Tech Stack

- Frontend: React 18, Vite
- UI and Icons: Tailwind CSS, Lucide React
- Architecture: Modular Component-Driven Design

---

## Getting Started

```bash
# Clone the repository
git clone https://github.com/tanzim557/school-management-system.git
cd school-management-system

# Install dependencies
npm install

# Run development server
npm run dev
```

Open http://localhost:5173 in your browser.
